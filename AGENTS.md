# Agent notes

- Static Marzipano 360° panorama viewer (generated by Marzipano Tool): `index.html` + `data.js` (scene config) + `index.js` (viewer logic), tiles under `tiles/<scene-id>/`. No build step, no backend, no secrets.
- Dev: `docker compose -f docker-compose.base44.yml up -d` runs `live-server` (via npx, needs network on first boot) on port 3000 with auto-reload on file changes.
- Verify: `curl localhost:3000/` returns index.html; `curl -I localhost:3000/tiles/0-car/preview.jpg` is 200. The panorama renders via WebGL, so screenshots may show it blank — check the DOM/console instead.
